# Sigma Premier Hotel

A static hotel booking website project built with HTML, CSS, and JavaScript. The pages and images are in the project root; no package installation or build step is required.

## Run locally

1. Install [Python](https://www.python.org/downloads/) if it is not already installed.
2. Open PowerShell or a terminal in this project folder.
3. Start a local web server:

   ```powershell
   py -m http.server 8000
   ```

   If `py` is not available, try:

   ```powershell
   python -m http.server 8000
   ```

4. Open [http://localhost:8000/homepage.html](http://localhost:8000/homepage.html) in your browser.
5. To stop the server, press **Ctrl+C** in the terminal.

You can also open `homepage.html` directly in a browser, but using the local server is recommended for consistent page navigation and browser storage.

## Notes

- The site loads some fonts and icons from external services, so an internet connection is needed for those assets.
- This is a front-end demo, not a production booking service. Authentication and payment processing are not configured. Do not enter real passwords or payment details.
